**Database Design**
This document outlines the main database tables that I will use within the restaurant ordering platform.

_User_
Stores the information about all the users within the system.

Field	          Type	            Description
id	          Primary Key    	Users unique identifier
username	    String	          Users login name
email	        String	          Users email address
password	    String	          Hashed password
first_name	  String	          Users first name
last_name	    String	           Users last name
phone_number	String	           Contact number
role	        String	          Customer, Staff, Manager, Admin, Owner
created_at	  DateTime	        Account creation date
updated_at	  DateTime	        Last account update


_Category_
Stores menu categories.

For example:
Burgers, Pizzas, Drinks, Desserts

Field	            Type	      Description
id	          Primary Key	    Unique category identifier
name	        String	        Category name
description	    Text	        Category description


_Menu Item_
Stores the individual food items.

Field	          Type	          Description
id	          Primary Key	      Unique item identifier
name	        String	            Item name
description	    Text	        Item description
price        	Decimal	       Current item price
image	          String	      Image path or URL
available	    Boolean	      Available for ordering
category_id  	Foreign Key	      Related category
created_at	  DateTime	      Created date
updated_at	  DateTime	      Last updated date


_Order_
Stores the customers orders.

Field	                    Type	        Description
id	                  Primary Key	    Unique order identifier
customer_id	          Foreign Key	    Customer who placed order
status	                String	       Current order status
total_price	            Decimal	        Order total
special_instructions	  Text	          Customer notes
created_at	          DateTime	        Order creation date
updated_at	          DateTime	        Last status update

Possible Status Values
Pending, Confirmed, Preparing, Ready, Completed, Cancelled


_Order Item_
Stores the items belonging to a specific order.

Field	                Type	        Description
id	                Primary Key	    Unique order item
order_id	          Foreign Key	    Related order
menu_item_id	      Foreign Key    	Ordered menu item
quantity	          Integer	        Quantity ordered
price_at_purchase	  Decimal	        Price when purchased

Example:
Order #101

2 Cheeseburgers
1 Cola
1 Fries
Each item becomes an Order Item record.

_Notification_
Stores notifications generated by the system.

Field	        Type	      Description
id	        Primary Key	  Notification identifier
user_id	    Foreign Key	  Related user
message    	Text	        Notification content
is_read	    Boolean	      Read status
created_at	DateTime	    Notification date

_Audit Log_
Stores any important actions performed within the system.

Examples include:
Menu item created/deleted, Price updated, Manager account created/deleted, Order cancelled

Field	        Type          	Description
id	        Primary Key	      Log identifier
user_id    	Foreign Key	      User who performed important action
action	    String	          Action performed
timestamp	  DateTime	        Date of action
