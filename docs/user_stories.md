**User Stories**

_Customer_
As a customer:
I want to create an account so that I can place orders and view my order hisotry
I want to be able to browse the menu so that I can decide what I would like to order
I want to add items to a cart so that I can review my order before checkout
I want to place an order through the website so that the restaurant can prepare my food
I want to receive updates on my order so that I can track its progress
I want to be able to view any of my own previous orders so that I can reorder food I regularly takeout easily

_Staff_
As a staff member:
I want to be able to view incoming orders so that I can begin preparing them
I want to update order statuses so that the customer is able to know what is going on behind the counter
I want to be able to mark menu items as unavailable to ensure customers don't order items whose ingredients are out of stock

_Manager_
As a manager:
I want to be able to add and edit menu items so that the menu is constantly up to date
I want to manage menu categories so that customers can easily browse products
I want to view the businesses analytics and track statistics so that I can monitor restuarants performance

_Admin_
As an admin:
I want to manage staff accounts and accesses so that the restaurant website remains secure
I want to have the ability to reset passwords so that user accounts can be recovered when necessary

_Owner_
As the owner:
I want access to reports and analytics so that I can make informed business decisions
I want to have the ability to manage administrators so that I can control access to the entire system
